в csrf необходимо работать с полем X-CSRF-Token, создать соль для хэширования токена и создать метод генерации и валидации токенов.
JWT Токены не исключают необходимость CSRF защиты.

Для Rate limiter необходимо сделать присваемую ко всем эндпоинтам в .py файле или к каждому отдельному эндпоинту настраиваемый рейт.
Можно реализовать в виде middleware.

JWT и Password Hasher - тривиальные задачи, главное подобрать правильные алгоритмы шифрования и свежие библиотеки. Вместо Bcrypt можно подобрать что то получше.
