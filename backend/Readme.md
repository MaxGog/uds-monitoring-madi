Для реализации проекта будут юзаться:
Redis/Postgres/Minio + две админки для первых двух.
FastAPI с его Pydantic (не нужно санитайзинг данных делать из за pydantic).
Работа с постгрес через UOW паттерн.
Авторизация согласно стандартам RFC, OAuth 2/2.1 - Stateful JWT.

Для виртуализации окружения используется быстрая библиотека uv

uv init - создать окружение в текущей папке. PyProject.toml - файл со всеми библиотеками, генерируется.
