Для предотвращения CSRF-like атак необходимо генерировать очень рандомное число в виде параметра state
Применять RSAES-OAEP и ECDSA  [RFC6979] алгоритмы шифрования
Также стоит брать какую либо уникальную сигнатуру устройства для валидации токенов, отклонять alg: none или др. поля
Стоит отслеживать, если один access token будет применяться другим аккаунтом, а также добавить claims для разных операций
UTF-8, issuer, subject, разные виды токенов
